# Lenta

Личное офлайн-первое PWA для питания, тренировок и здоровья. На двоих.
Сервера нет, рекламы нет, подписок нет, аналитики нет. Данные лежат только
в вашем браузере.

Реализовано по `TZ.md`. Все решения из раздела 2 ТЗ выполнены буквально:
входа по почте нет, игровой слой «тихий», AI по умолчанию выключен, шаги
вводятся руками.

---

## Как запустить у себя

Нужен Node.js 20 или новее. Дальше три команды:

```bash
npm install     # поставить зависимости (один раз)
npm run dev     # запустить для разработки → http://localhost:5173
npm run build   # собрать готовое приложение в папку dist/
```

Готовое приложение — это папка `dist`. Её содержимое можно положить на любой
бесплатный статический хостинг: Netlify, Vercel, GitHub Pages. Ничего
настраивать не нужно, серверная часть отсутствует.

**Важно:** сайт должен открываться по HTTPS — иначе браузер не даст доступ к
камере, а без неё не работает сканирование штрихкодов.

## Первый запуск на телефоне

1. Откройте адрес приложения в браузере телефона.
2. Создайте профиль («Я», «Жена» — имена настраиваются).
3. Пройдите онбординг: он спросит рост, вес, цель и уровень активности,
   затем покажет вашу норму и объяснит, откуда взялась каждая цифра.
4. **Добавьте приложение на домашний экран.** Это не украшение: iOS удаляет
   данные сайтов, которыми не пользовались 7 дней, и исключение делает только
   для приложений с домашнего экрана.
   - iPhone: Safari → «Поделиться» → «На экран „Домой“»
   - Android: Chrome → меню (⋮) → «Установить приложение»
   - Компьютер: значок установки в адресной строке
5. На последнем шаге онбординга нажмите «Включить устойчивое хранилище».

После этого приложение работает полностью офлайн — в самолёте, в подвальном
зале, где угодно.

## Резервные копии

Данные существуют в одном экземпляре, в вашем браузере. Раз в неделю
приложение само напомнит скачать копию — это одна кнопка и один файл.
**Не пропускайте это напоминание.**

Копия — обычный `.json`-файл. Загрузить её обратно можно в трёх режимах:
предпросмотр (посмотреть, сколько записей добавится), добавить недостающее,
заменить всё.

Опционально копию можно складывать на ваш Google Диск — в служебную папку,
невидимую среди ваших файлов. Разовая настройка описана в
[docs/google-drive-setup.md](docs/google-drive-setup.md). Подключать Диск
не обязательно: ручной экспорт файла — полноценный способ.

## Что появилось в версии 0.7

- **Правка завершённой тренировки.** Карточка в истории открывается нажатием;
  внутри — кнопка «Изменить»: вес, повторы, RPE, тип подхода, добавление и
  удаление подходов и упражнений, название, дата, заметка, самочувствие.
  Тоннаж и число подходов пересчитываются сами. Удаление — свайпом влево,
  с плашкой «Вернуть» на пять секунд.
- **Планирование заранее.** Раздел «Зал → План»: календарь на месяц, точка
  на дне с тренировкой, цвет точки по статусу. План создаётся из дня программы
  (состав подставляется и дальше правится свободно) или пустым. Есть массовое
  «запланировать на N недель вперёд» и перенос со сдвигом последующих.
  Просроченный план не пропадает — предлагает перенос на сегодня или пропуск.
  Строка «Ближайшее» на главном экране теперь берёт данные отсюда.
- **Привычки-отказы.** При создании привычки выбирается «хочу делать» или
  «хочу бросить». У второй — крупный счётчик дней воздержания, лучшая серия и
  число срывов. **Пропущенный день серию не обнуляет**: она сбрасывается
  только явной отметкой срыва, спрятанной за свайпом. Вехи 1, 3, 7, 14, 30,
  60, 90, 180 и 365 дней отмечаются в достижениях.
- **Программы из шаблонов редактируются полностью** — дни, состав, порядок,
  подходы, повторы, отдых, суперсеты. Есть «вернуть как в шаблоне» с отменой
  и «отвязать от программы». Упражнение, добавленное прямо в зале, по
  умолчанию остаётся только в этой тренировке — закрепить его в программе
  предлагается отдельно.
- **Панели закрываются четырьмя способами** — кнопкой, фоном, свайпом вниз и
  клавишей Esc. Пустая форма закрывается молча; если что-то введено,
  предлагается сохранить, не сохранять или продолжить ввод.
- **Разделы стали различимы**: своя иконка у каждого, единые заголовки групп,
  три уровня поверхностей, единый компонент числовой метрики.

## Что нужно от вас

1. **Заведите свои продукты.** Встроенный набор — 221 базовый продукт
   (мясо, крупы, овощи, молочное, готовые блюда). Российские бренды в
   бесплатных базах покрыты плохо, поэтому первые недели придётся завести
   30–50 своих позиций. После этого поиск почти всегда будет попадать с
   первой буквы. Свои продукты всегда идут первыми в выдаче.

   Часто повторяющиеся продукты удобнее один раз вписать в
   `scripts/foods-data.mjs` и выполнить `node scripts/build-foods.mjs` —
   тогда они попадут во встроенный набор и переживут любую переустановку.

2. **Проверьте набор блинов и вес грифа** в настройках — от них зависит
   плита-калькулятор.

3. **Решите про AI.** По умолчанию он выключен целиком, и приложение об этом
   даже не упоминает. Без AI не работает только распознавание еды по фото;
   у остальных функций есть полноценные детерминированные замены.

## Команды

```bash
npm run dev            # разработка
npm run build          # сборка
npm test               # тесты расчётов (198 штук)
npm run test:coverage  # покрытие domain/
npm run e2e            # сквозные сценарии в браузере
npm run lint           # проверка правил из ТЗ
npm run check:spec     # регулярная проверка по разделу 22 ТЗ
npm run check:contrast # контраст пар «текст/фон» в обеих темах
npm run seed:exercises # пересобрать базу упражнений
npm run seed:images    # скачать картинки упражнений для полного офлайна
npm run fonts          # перекачать шрифты
```

## Источники данных

- Встроенный набор продуктов — значения USDA FoodData Central, общественное
  достояние.
- Поиск в интернете — Open Food Facts (лицензия ODbL) и USDA FoodData
  Central. Найденное сохраняется локально, второй раз сеть не нужна.
- База упражнений — [free-exercise-db](https://github.com/yuhonas/free-exercise-db),
  общественное достояние.
