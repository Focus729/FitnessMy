# Правила разработки

Эти правила взяты из `TZ.md` и обязательны. Три из них проверяются
автоматически (`npm run lint`, `npm run check:spec`), остальные — глазами
при ревью.

## 1. Главный экран: пять блоков и ни одним больше

Раздел 13 ТЗ. **Ничего не добавляется на «Сегодня» без удаления чего-то
другого.** Перегруженность интерфейса — главный раздражитель заказчика (K4),
и правило пяти блоков существует, чтобы приложение через год не выглядело как
то, от чего от него уходили.

Блоки размечены в `src/screens/Today.tsx` комментариями `{/* N — ... */}`;
`npm run check:spec` считает их и падает на шестом.

## 2. UI не знает о Dexie

Решение 2.9 ТЗ. Весь доступ к данным — через `src/data/repositories/*`.
Ни один компонент не импортирует `dexie`, `dexie-react-hooks` или
`src/data/db/*`. Проверяется правилом ESLint `no-restricted-imports`.

Зачем: добавление серверной синхронизации в будущем должно быть новой
реализацией тех же интерфейсов, а не переписыванием приложения.

## 3. Домен — чистые функции

Раздел 5.1. `src/domain/**` не знает о React, Dexie и сети. Любая формула
живёт там и покрыта юнит-тестами. Покрытие `domain/` — не ниже 90%.

Если формула появилась в компоненте — это ошибка, её нужно перенести.

## 4. Ни одной строки текста в компонентах

Раздел 17. Только ключи i18n и `t()`. Оба словаря — `src/i18n/ru.json` и
`src/i18n/en.json` — обновляются вместе; английский не заглушка, а полный
перевод. Проверяется ESLint и `npm run check:spec`.

Числа, знаки препинания и односимвольные значки — исключение.

## 5. Внешние адаптеры всегда опциональны

Раздел 5.3. Приложение обязано полностью работать:

- без сети,
- без AI-ключа,
- без входа в Google.

Ни один внешний запрос не уходит без явного действия пользователя (19.4).
Поиск в интернете — только по нажатию «Искать в интернете», никогда
автоматически.

## 6. Единицы — базовые

Раздел 5.5. В модели: граммы, миллилитры, килокалории, сантиметры, секунды.
Имперские единицы существуют только на уровне отображения
(`src/lib/format.ts`).

## 7. Бандл — не более 400 КБ gzip

Раздел 19.2, без учёта встроенных наборов данных. Каждая новая зависимость
сверх списка из раздела 4 требует обоснования в описании изменений.

Наборы продуктов и упражнений, графики и сканер штрихкода вынесены в
отдельные чанки и в путь первой отрисовки не входят.

## 8. Взаимодействие

Раздел 18.5:

- область нажатия не менее 44×44 — приложением пользуются потными руками в зале;
- диалоги ввода — выезжающие снизу панели, не модальные окна по центру;
- разрушающие действия — через свайп или долгое нажатие, никогда одиночным;
- отмена вместо подтверждения: «Удалено. Вернуть» на 5 секунд. Диалогов
  «Вы уверены?» нет нигде, кроме удаления профиля и импорта с заменой;
- состояние не передаётся одним лишь цветом (19.3) — рядом всегда знак.

## 9. Цвет

Раздел 18.2. Палитра — шесть значений на тему плюс две семантические.
Акцент один и занимает не более 5% площади экрана. Градиентов нет, теней нет,
кроме одной под выезжающими листами. Семантические цвета появляются только
при фактическом отклонении.

## 10. Что мы не делаем

Список из раздела 21 закрыт. Если функция в нём — она не обсуждается заново.
Коротко: сервера, реального времени между устройствами, интеграций с
носимыми устройствами, GPS, микронутриентов, уведомлений, отчётов в CSV/PDF,
рекламы и подписок — нет.
