# Резервная копия на Google Диск: пошаговая настройка

Эта настройка **не обязательна**. Ручной экспорт файла — полноценный способ
резервного копирования, и приложение никуда вас не подталкивает. Диск нужен
только если вам удобнее, чтобы копия сохранялась сама.

Настройка разовая, занимает 10–15 минут. Инструкция написана для человека,
который никогда не заходил в Google Cloud Console — потому что так и есть.

---

## Что мы вообще делаем и почему это выглядит сложно

У приложения нет сервера. Значит, чтобы оно могло положить файл на **ваш**
Диск, Google должен знать, что это за приложение. Регистрация приложения у
Google — и есть вся эта возня. Один раз.

Приложение попросит ровно один доступ: `drive.appdata` — служебная папка
приложения. Она **невидима** в интерфейсе Диска, недоступна другим
приложениям, и приложение не увидит ни одного вашего файла. Только свои копии.

---

## Шаг 1. Открыть Google Cloud Console

1. Зайдите на [console.cloud.google.com](https://console.cloud.google.com/)
   под тем аккаунтом Google, на Диск которого хотите класть копии.
2. Если это первый заход, Google предложит принять условия — примите.

> **Что вы увидите:** тёмно-синяя шапка со словами Google Cloud и выпадающий
> список проектов слева от строки поиска.

## Шаг 2. Создать проект

1. Нажмите на выпадающий список проектов в шапке (слева, рядом с надписью
   Google Cloud).
2. В открывшемся окне — кнопка **New project** («Создать проект») справа
   вверху.
3. Название: `Lenta`. Организацию оставьте как есть.
4. Нажмите **Create**. Подождите 10–20 секунд.
5. Убедитесь, что в шапке теперь выбран проект `Lenta` — если нет, выберите
   его в том же списке.

> **Что вы увидите:** после создания появится уведомление-колокольчик, а имя
> проекта сменится в шапке.

## Шаг 3. Включить Google Drive API

1. В строке поиска вверху введите `Google Drive API`.
2. Выберите **Google Drive API** из результатов (раздел Marketplace).
3. Нажмите синюю кнопку **Enable** («Включить»).
4. Подождите, пока страница перезагрузится.

> **Что вы увидите:** после включения кнопка Enable сменится на Manage, а
> слева появится меню с пунктами Overview, Quotas, Credentials.

## Шаг 4. Настроить экран согласия

Google требует описать приложение, прежде чем выдать ключ.

1. В строке поиска введите `OAuth consent screen` и откройте этот раздел.
2. Тип пользователей: **External** («Внешние»). Нажмите **Create**.
3. Заполните обязательные поля:
   - App name: `Lenta`
   - User support email: ваша почта (выберите из списка)
   - Developer contact information: та же почта
4. Нажмите **Save and continue**.
5. Экран **Scopes** — ничего не добавляйте, нажмите **Save and continue**.
6. Экран **Test users** — нажмите **Add users** и добавьте свою почту
   (и почту супруги, если она тоже будет пользоваться). Затем **Save and
   continue**.
7. На последнем экране нажмите **Back to dashboard**.

> **Важно:** приложение останется в статусе Testing — это нормально.
> Публиковать его не нужно, вы единственные пользователи. В статусе Testing
> доступ живёт 7 дней, после чего вход нужно повторить — приложение просто
> попросит вас нажать «Подключить» ещё раз.

## Шаг 5. Создать OAuth Client ID

1. В строке поиска введите `Credentials` и откройте раздел.
2. Нажмите **+ Create credentials** вверху → **OAuth client ID**.
3. Application type: **Web application**.
4. Name: `Lenta Web`.
5. В разделе **Authorized JavaScript origins** нажмите **+ Add URI** и
   впишите адрес, по которому у вас открывается приложение. Например:
   - `https://lenta.example.com` — если вы выложили его на хостинг
   - `http://localhost:5173` — если запускаете у себя на компьютере

   Можно добавить оба.

   > Адрес пишется **без** слеша на конце и **без** пути. Только протокол и
   > домен. Это самая частая причина, по которой потом ничего не работает.

6. Раздел **Authorized redirect URIs** заполнять не нужно.
7. Нажмите **Create**.

> **Что вы увидите:** окно с двумя строками — Client ID и Client secret.

## Шаг 6. Скопировать Client ID в приложение

1. Скопируйте **Client ID** — длинную строку вида
   `123456789012-abcdefghijklmnop.apps.googleusercontent.com`.
2. Client secret **не нужен**. Приложение работает без него.
3. Откройте Lenta → **Настройки** → раздел «Данные» → «Резервная копия на
   Google Диск».
4. Вставьте Client ID в поле **OAuth Client ID**.
5. Нажмите **Сохранить копию на Диск**.
6. Google откроет окно выбора аккаунта. Выберите тот же аккаунт.
7. Появится предупреждение «Google hasn't verified this app» — это ожидаемо
   для приложения в статусе Testing. Нажмите **Advanced** → **Go to Lenta
   (unsafe)**. Приложение ваше, ключ ваш, данные ваши.
8. Разрешите доступ. Копия сохранится.

---

## Как это работает дальше

- Копия сохраняется по кнопке **«Сохранить копию на Диск»**.
- Автоматически — при закрытии вкладки, если с прошлой копии прошло больше
  суток.
- Хранятся последние 5 копий, старые удаляются сами.
- **«Восстановить с Диска»** показывает список копий с датами.

**Это резервное копирование, а не синхронизация.** Записи не переносятся
между устройствами в реальном времени. Если вы ведёте дневник на телефоне и
на ноутбуке одновременно, они разойдутся, и восстановление копии перезапишет
одну версию другой. Так задумано (раздел 16.3 ТЗ).

## Если что-то не работает

| Что видите | В чём дело |
|---|---|
| Окно Google не открывается | Браузер заблокировал всплывающее окно — разрешите его для этого сайта |
| `redirect_uri_mismatch` или `origin mismatch` | Адрес в Authorized JavaScript origins не совпадает с адресом сайта. Проверьте протокол (`http` против `https`), отсутствие слеша на конце и порт |
| `access_denied` | Ваша почта не добавлена в Test users на экране согласия (шаг 4.6) |
| Просит войти каждые 7 дней | Нормально для статуса Testing. Просто нажмите «Подключить» снова |
| «Не удалось» без подробностей | Проверьте, включён ли Google Drive API (шаг 3) |

Если возиться не хочется — не возитесь. Скачивайте файл кнопкой раз в неделю,
когда приложение напомнит. Это ровно та же копия.
